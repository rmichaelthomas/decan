# Decan C2–C6 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish Decan as a verified `durable-occurrences` reference by carrying forward C0/C1, then implementing C2 semantic validation, C3–C5 exact temporal-core evidence, and C6 SQLite-backed append-only Occurrences.

**Architecture:** Decan remains one private Node 22.13+ TypeScript package. C2 is a pure validation layer; C3–C5 resolve finite candidate sets solely from explicit immutable snapshots; C6 materializes only an intact, selected resolved candidate into append-only Occurrence history. The runtime capability registry is the only support claim surface, and no stage may cross the execution boundary.

**Tech Stack:** Node.js >=22.13, TypeScript (strict), Vitest, `@js-temporal/polyfill`, `node:sqlite`, `json-canonicalize`, and `fast-check`.

**Spec:** `docs/superpowers/specs/2026-08-27-decan-c2-c6-design.md`; `references/decan_checkpoint_v0_7_human_policy_naming_roadmap_closure.md`; `references/scheduling_language_checkpoint_v0_5_runtime_reference_conformance.md` §§42–60.

## Global Constraints

- Start from the existing verified C0/C1 source, tests, fixtures, and lockfile; do not rewrite it from scratch.
- Keep package metadata private and set its local name to `decan`; do not publish or create a GitHub remote.
- Copy the full v0.1–v0.7 checkpoint chain into `references/` unchanged.
- Do not access clock, locale, timezone, geography, network, live calendars, or observers implicitly.
- A missing dependency is a typed validation dependency or resolution `needs`, never a guessed default.
- Preserve the distinctions Parsed / Validated / Resolved / Materialized; keep `ok: false` separate from valid domain states.
- Do not add Binding, Action, authority, execution, retry, result, verification, fulfillment, cron/RRULE, dynamic observers, or a scheduler service.
- C6 uses the built-in `node:sqlite` `DatabaseSync` adapter; `engines.node` must be `>=22.13.0`.
