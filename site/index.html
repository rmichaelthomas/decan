The layer before schedules. Decan preserves what someone meant about time before that intent is flattened into a trigger, timestamp, or job.
Human-first. Temporal source is readable, reviewable, and centered on semantic blocks instead of opaque recurrence strings.
Agent-friendly. Parse, canonicalize, validate, classify support, resolve with snapshots, materialize candidates, and report gaps without ambient guessing.

Use it from a shell or an agent host.

The CLI is the direct operational surface. The MCP server exposes the same Decan core as model-callable tools, resources, and prompts.

decan canonicalize intent.ti
decan validate intent.ti
decan resolve intent.ti --reference-time 2026-08-27T12:00:00Z --horizon-count 3 --context context.json
decan import-cron "0 9 * * 1" --effective-from 2026-08-27

What it refuses.

Decan does not read ambient locale, timezone, clock, geolocation, network, account state, or live observers. It does not authorize, execute, retry, verify, or fulfill work. If context is missing, Decan says what it needs.

Decan is currently a private reference implementation with no license declared. Treat Proper Time as a standards-shaped proposal and Decan as the executable argument.
